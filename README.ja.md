# GS Map Editor

[English](README.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · **日本語**

*これは英語版 [README.md](README.md) の翻訳です。内容が異なる場合は、英語版が最新です。*

コードを書かずに、自分だけの **Golden Sun: The Broken Seal** を作れます。町を塗り直したり、宝箱を隠したり、新しいセリフを書いたり、人物やドアを追加したり、ワールドマップの形を変えたりしたら、**▶ プレイ** を押して、変更した世界を歩き回ってみましょう。満足したら、共有用の小さなパッチを書き出せます。

このエディターは [alchemy](https://github.com/PascalPixel/alchemy) を使って動きます。alchemy は、読めるソースファイルからゲームを作り直すプロジェクトです。エディターはそのソースからあなたのコンピューター上でゲームをビルドするので、MOD を作るのに ROM は必要ありません。

> **プレビュー版: テスターを募集しています。** このエディターが対応しているのは The Broken Seal の英語版で、macOS と、試験的に Windows で動きます。これまで主に1台の Intel Mac でテストしてきただけで、Windows 版はまだ実際の Windows PC で動かしたことがありません。そのため、「うまく動いた」という報告も含めて、どんな報告も助かります: [ダウンロード](https://github.com/TRosenvall/GS-Map-Editor/releases)して試し、[結果を教えてください](https://github.com/TRosenvall/GS-Map-Editor/issues/new?template=bug_report.md)。大切な MOD は必ずバックアップしておいてください。

**alchemy のバージョン:** このエディターは alchemy のコミット [`5ca23b1fe1`](https://github.com/PascalPixel/alchemy/commit/5ca23b1fe1774f954aacfbd7db35c8c9b9a59184)（2026-11-12）でテストしています。セットアップではちょうどそのコミットをダウンロードします。alchemy は変化が速いので、新しいコピーはエディターが追いつくまで動かないことがあります。

## はじめに

### 必要なもの

- macOS 11 以降の Mac、または Windows 10 か 11 の PC。
- ゲームのソースとそのビルドのために、約 3 GB の空き容量。
- ゲームを遊ぶための無料のゲームボーイアドバンスエミュレーター [mGBA](https://mgba.io/downloads.html)（Windows では Windows 用インストーラー）。
- 最初のセットアップ用のインターネット接続。

### アプリを入手する（Mac）

[Releases](https://github.com/TRosenvall/GS-Map-Editor/releases) から最新の `.dmg` をダウンロードします:

- **AppleSilicon** は M1、M2、M3、M4 以降のチップを積んだ Mac 用です。
- **Mac-Intel** は Intel Mac 用です。

どちらかわからない場合は、Apple メニュー →「**この Mac について**」を開きます。「チップ: Apple M…」とあれば Apple Silicon です。

`.dmg` を開いて、**GS Map Editor** を「**アプリケーション**」にドラッグします。

### 初めて開くとき（Mac）

このアプリはまだ Apple の開発者証明書で署名されていないため、初回は macOS が警告を出します:

1. 「アプリケーション」から開きます。macOS がアプリを確認できないと表示するので、「**完了**」（または「**キャンセル**」）を押します。
2. 「**システム設定 → プライバシーとセキュリティ**」を開き、下までスクロールして、GS Map Editor の横にある「**このまま開く**」を押します。パスワードを入力して確定します。

macOS 14 以前では、代わりにアプリを右クリックして「**開く**」を選び、もう一度「**開く**」を押す方法もあります。2回目からは普通に開きます。

アプリを自分でビルドしたい場合は、開発者向けノートの[デスクトップアプリ](docs/ja/DEVELOPING.md#デスクトップアプリmacos)の手順に従ってください。ターミナルに慣れていて、ビルド済みの alchemy のチェックアウトをすでに持っているなら、アプリを使わずに `python3 server.py --root /path/to/alchemy` を実行してから、次のアドレスを開くこともできます: http://127.0.0.1:8765/.

### エディターを入手する（Windows、試験版）

エディターは Windows に組み込まれた Linux である WSL の中で動きます。Windows でゲームのソースをビルドするには、それしか方法がないためです。エディターはウェブブラウザーで開きます。

1. [Releases](https://github.com/TRosenvall/GS-Map-Editor/releases) から `Install-GS-Map-Editor.cmd` をダウンロードします。ブラウザーが「一般的にダウンロードされていません」と表示したら、「**保存**」を選びます。
2. ダブルクリックします。インストーラーがまだ署名されていないため、Windows が「PC を保護しました」と表示します。「**詳細情報**」を押してから「**実行**」を押します。
3. 初回は WSL を有効にして Ubuntu をインストールします。Windows が管理者の許可を求め、再起動を求めることもあります。その場合は再起動して、もう一度インストーラーをダブルクリックしてください。
4. Ubuntu に聞かれたら、ユーザー名とパスワードを決めます。パスワードを入力しても何も表示されませんが、正常です。次の手順でそのパスワードを聞かれます。
5. インストーラーが Ubuntu の中にエディターを準備し、スタートメニューとデスクトップに **GS Map Editor** を追加します。

**GS Map Editor** を開きます。小さなウィンドウが表示されます。閉じるとエディターが止まるので、エディターを使っている間は開いたままにしてください。エディターはブラウザーで開きます。インストーラーをもう一度実行すると、エディターはそのインストーラーに付属するバージョンに更新されます。

Windows では、キーボードショートカットはこのガイドで ⌘ とある所は Ctrl、⌥ とある所は Alt を使います。書き出したパッチとパッチを当てたゲームは、Mac と同じように「**ドキュメント\\GSMapEditor**」に保存されます。ゲームのソースとそのビルドは、そこでビルドするほうがずっと速いため、Ubuntu の中、Ubuntu のホームフォルダーにある `GSMapEditor` に置かれます。エクスプローラーでは「**Linux → Ubuntu → home**」の下に表示されます。

### 初回セットアップ

初回は、エディターがチェックリストの画面で開きます。所要時間は約 15 分で、ほとんどは待ち時間です。各手順のボタンを押せば、あとはエディターがやってくれます:

1. **Apple の開発者ツール**（Mac のみ）: Apple のインストーラーを開きます。
2. **ゲームをビルドするためのツール:** Mac ではアプリに同梱済みで、Windows ではインストーラーが用意します。
3. **ゲームのソース:** alchemy を `~/Documents/GSMapEditor/` にダウンロードします（Windows では Ubuntu のホームフォルダーの `GSMapEditor`）。すでにコピーを持っている場合は、「**すでにコピーを持っている…**」を選び、そのフォルダーを指定します。
4. **ビルドの準備:** ゲームのコンパイラーを1回だけ準備します。
5. **ゲームの最初のビルド:** ゲームを1回ビルドします。

最後に「**エディターを開く**」を押します。これ以降、アプリは直接エディターで開きます。

## 2分でできる初めての MOD

1. 左の一覧から場所を選びます。「**場所を探す**」欄に入力すると検索できます。
2. 上部バーの「**宝箱**」を押し、何もない地面をクリックします。
3. `Herb` などのアイテム名を入力し、「**宝箱を追加**」を押します。
4. 「**▶ プレイ**」を押します。ゲームが mGBA で開き、ゲームが起動して数秒後に、編集していた場所に移ります。
5. 宝箱まで歩いて行って開けてみましょう。

## エディターの画面構成

| エリア | あるもの |
|---|---|
| **左** | 場所の一覧。ワールドマップはいちばん上にあります。 |
| **上部バー** | ズーム、レイヤー、オーバーレイ、ツール、そして保存・チェック・プレイのボタン。 |
| **中央** | マップ。 |
| **右** | 使っているツールのパネル。 |
| **最下行** | ステータスメッセージ。カーソルを合わせると、その場所が何をするかを表示します。たとえば「宝箱: Herb」や、出口の行き先などです。どのマスかも表示されます。マスの番号は、チェック、ドア、宝箱が使うものと同じです。 |

上部バーの「**詳細表示**」にチェックを入れると、生の数値やコードと、独立した「**ビルド**」ボタンが表示されます。普通の編集では必要ありません。

### 言語

エディターは英語、スペイン語（Español）、ドイツ語（Deutsch）、フランス語（Français）、イタリア語（Italiano）、日本語に対応しています。コンピューターの言語に対応していれば、その言語で起動します。言語は 🌐 メニューで変えられます。このメニューは最初のセットアップ画面の右上と、上部バーの右端にあります。変わるのはエディター自身の言葉だけです。改造しているゲームは英語版なので、地名、人物、アイテム、そしてあなたが書くセリフは英語のままです。

このガイドも翻訳されています。いちばん上のリンクを見てください。エディターとこのガイドの翻訳は AI の助けを借りて作ったもので、まだすべてをネイティブスピーカーが確認したわけではありません。翻訳版のガイドが英語版と異なる場合は、英語版のガイドが最新です。読みにくい所があれば、期待する言い回しを添えて[お知らせください](https://github.com/TRosenvall/GS-Map-Editor/issues/new?template=bug_report.md)。

## 保存と元に戻す

保存を待つ変更と、すぐに保存される変更があります:

| 「**保存**」（または ⌘S）を待つもの | すぐに保存されるもの |
|---|---|
| ペイント、通行設定、高さ | 宝箱の追加・変更・削除 |
| スタンプの貼り付け | イベントとドア |
| 宝箱・ストーン・人物のドラッグ | ワールドマップのペイントと町の移動 |

場所を切り替える前、ワールドマップに移る前、プレイを押す前にも、エディターが代わりに保存するので、先に進んでも作業は失われません。保存が拒否された場合は、その場に留まり、最下行に理由が表示されます。

元に戻す方法は3つあります:

- 「**元に戻す**」（⌘Z）は、直前の変更を、何であっても取り消します。まだ保存していないペイントが先で、次に保存済みの操作を新しい順に、どのツールのどの場所のものでも取り消します。人物、宝箱、ドア、イベントの追加、ワールドマップのひと塗り、どれでもです。ボタンのツールチップに何をどこで取り消すかが表示され、エディターがその場所を開いて見せます。保存済みの操作は最後の 30 個まで、エディターを閉じた後も残ります。
- 「**やり直す**」（⇧⌘Z）は、新しい変更をするまでの間、「元に戻す」で取り消したものを戻します。
- 「**場所をリセット…**」は、場所のマップ、読み込んだ画像、その場所自身の人物・ドア・イベントを、元のゲームの状態に戻します。気が変わったら、「**元に戻す**」であなたの版が戻ります。マップをほかの場所と共有している場所なら、そちらも一緒に戻るので、エディターが先に警告します。ほかの場所と共有している人物やイベントは、あなたが指定しない限りそのままです。エディターが確認します。
- ワールドマップのページにある「**ワールドマップをリセット…**」は、ワールドマップに対して同じことをします。

あなたが書いたテキストは、どれかのイベントがその一部でも使っている間は、ゲームのテキストファイルに残ります。あなたの行がどこにも使われなくなって初めて削除されます。未保存の変更があるときに保存済みの操作を元に戻すと、その未保存の変更も破棄されます。その場合は先に確認されます。

保存は毎回、全部成功するか、何もしないかのどちらかです。エディターが途中で止まった場合は、次に起動したときに、途中までの保存の取り消しを完了します。ファイルが書き込めない場合（たとえば Finder でロックされているなど）、保存は拒否され、残りは取り消されます。

## 見て回る

「**表示**」（V）を押すと、何も変えずに見て回れます。

- **ズーム:** 1× から 4× まで。
- **レイヤー:** 各場所には最大3つのレイヤーがあり、「**地面**」「**中間**」「**頭上**」と呼びます。それぞれ非表示にできます。「**詳細表示**」にチェックを入れると、薄くするスライダーが表示されます。
- **オーバーレイ:** 「**通行設定**」、地面の高さを見る「**高さ**」、マス目を見る「**グリッド**」にチェックを入れます。
- **宝箱**は常にマップに表示されます。ドア、人物、イベントは、それぞれのツールを使うと表示されます。

## ペイント: 地面の見た目

「**ペイント**」（B）を押します。

1. 上部バーの「**レイヤー**」メニューでレイヤーを選びます。
2. 右の「**ブロック**」パネルからブロックを選びます。または ⌥ を押しながらマップをクリックすると、カーソルの下のブロックを拾えます。
3. マップ上でクリックするかドラッグします。
4. 保存します。

上部バーの「**塗りつぶし**」にチェックを入れる（または F を押す）と、クリックしたマスと同じブロックが続いている範囲全体が、そのレイヤーで塗りつぶされます。塗りつぶしは「**通行設定**」と「**高さ**」でも使え、その場合はブロックの代わりに通行設定や高さが同じ範囲を塗ります。「元に戻す」は1回の塗りつぶし全体をまとめて取り消します。

ブロックのセットは場所ごとに異なるので、パネルの中身は場所によって変わります。

## 通行設定: 歩ける場所

「**通行設定**」（C）を押します。ブロックをペイントしても歩ける場所は変わらないので、これは別の手順です。ブラシを選んでペイントします。

| ブラシ | 何をするか |
|---|---|
| **床** | 歩ける普通の地面。 |
| **壁** | 高さに関係なく、通れなくします。 |
| **段差（飛び降りる）** | 下を押したまま少し待つと、先頭のキャラクターが飛び降ります。 |
| **登れる壁・はしご** | 上か下を押したまま少し待つと、登り降りします。 |
| **ジャンプする隙間（前へ跳ぶ）** | 押し続けて少し待つと、先頭のキャラクターが飛び越えます。向こう側が着地できる場合に限ります。 |
| **エンカウント地面 A / B** | 歩けます。ランダムバトルは、その場所の1つ目または2つ目のエンカウントゾーンを使います。 |
| **ダメージ床** | 歩けますが、シーンがその設定を有効にしていれば、一定の歩数でパーティーがダメージを受けます。 |
| **Cloak の影** | 歩けます。エナジー Cloak でパーティーが隠れたままでいられる唯一の地面です。 |
| **空のつぼ・たる・木箱・墓・本・井戸** | 調べても何も見つかりません。高さによって、たいていは壁にもなります。 |

宝箱、ドア、イベントのツールは、必要な特殊コードを自分で設定するので、それらをペイントする必要はありません。

## 高さ: 地面の高さ

「**高さ**」（H）を押します。パネルには、この場所ですでに使われている高さが、高いものから順に「レベル 3」や「スロープ、左から右へレベル 2〜4」のように一覧表示されます。同じ表示になる高さには番号が付き、カーソルを合わせると何マスで使われているかがわかります。1つ選んでペイントします。マップでは青が濃いほど地面が高く、一覧の各高さにはその色が付いています。その場所でいちばん低い地面には青がないので、マップの下の港や浜辺には何も表示されません。

高さはゲーム自身の単位であるレベルで数えます（1レベルは 8 ピクセル、半マス分）。高さは見た目だけでなく、歩き方にも影響します。人物は立っている地面の高さに立ち、パーティーは一度に1レベルずつしか上り下りできません。2レベル以上の差は壁として働きます。スロープはレベルをつなぎ、スロープ1マスで2レベル上れるので、階段や坂道はスロープを並べたものです。

## 宝箱

「**宝箱**」（K）を押します。

- **追加する:** 何もない場所をクリックし、「**アイテム**」（名前を入力し始めると絞り込めます）か「**コイン**」の額を選んで、「**宝箱を追加**」を押します。
- **変更する:** 宝箱をクリックし、中身を変えて確定します。
- **削除する:** 宝箱をクリックし、「**宝箱を削除**」を押します。
- **移動する:** ドラッグしてから保存します。エナジーストーンもドラッグできます。すでにドア、看板、足元メッセージになっているマスには、宝箱を置けません。

宝箱が開けられたことを覚えておくフラグも含めて、残りはエディターが処理するので、戻ってきても宝箱は空のままです。1つの場所に置けるのは、宝箱とエナジーストーン合わせて最大 **10 個**です。ほかの調べる場所は 10 個に数えません。

## イベント: 人物、看板、メッセージ

「**イベント**」（E）を押します。パネルには、この場所で起きることがすべて言葉で一覧表示されます: 人物のセリフ、Mind Read で読める心の声、看板、足元メッセージ、調べる場所、出口エリアです。人物はマップ上にその姿で表示され、カーソルを合わせるとその人物のセリフが見られます。シーンスクリプトはわかりやすい言葉で説明されます（全文は「**詳細表示**」にチェックを入れると見られます）。ストーリーで登場するまでマップの外で待っている人物は描かれず、パネルにその人数が表示されます。

いちばん上の「**ストーリー段階**」が大切です。多くの場所はストーリーが進むにつれて変わり、段階ごとに人物とイベントがあります。編集したい段階を選んでください。

### 追加する

マップ上の場所をクリックしてから、次の中から選びます:

- 「**看板を追加（Aで読む）…**」は、看板や調べられるもの用です。
- 「**足元メッセージを追加…**」は、そこを踏んだときに表示されるメッセージ用です。そこに立っている間は繰り返されないので、プレイヤーが閉じ込められることはなく、一度離れて戻ってくるとまた表示されます。
- 「**ここに人物を追加…**」では、絵のプレビューを見ながら誰にするかを選び、「**歩き回る**」かどうかを決めます。エディターはまずその場所を確認します（下を参照）。

自分で追加した人物を消すには、その人物をクリックして「**この人物を削除**」を押します。セリフも一緒に消えます。ゲームにもともといる人物は、ストーリーが動かしたり話しかけたりするので削除できませんが、移動はできます。

### 人が立てる場所

開けて見える場所がどこでも、人を立たせるのに向いているわけではありません。いちばん上の「**人が立てる場所**」にチェックを入れるか、単に「**ここに人物を追加…**」を押すと、そこに人がいたらどうなるかでマップが色分けされます:

| 色 | 意味 |
|---|---|
| 緑 | パーティーが歩いて近づき、話しかけられます。 |
| 黄 | パーティーはそのマスに入れませんが、カウンター越しの店員のように、横から話しかけられます。 |
| 青 | Imil のように、パーティーが滑って渡る氷です。そこに人が立つと、滑るのを邪魔します。 |
| 橙 | ドア、出口、または踏むと反応する場所です。そこに人がいると邪魔になります。 |
| 赤 | パーティーが歩いて、話しかけられる距離まで近づけません。 |

これはゲーム自身の歩行ルールから、パーティーがその場所に到着するすべての地点を起点に割り出しています: 一度に1レベルずつ上り下りでき、壁で止まり、2マス以内の人には話しかけられます。エナジーやストーリーでしか開かない場所は赤く表示されるので、そこが赤でも必ずしも間違いとは限りません。

場所に問題があると、エディターはそれをわかりやすい言葉で伝えます。たとえば「ここの地面はいちばん近い道より 4 レベル高い」や、そこに立つとパーティーがドアへ行けなくなる、といった具合です。そのうえで、回避策を提案します:

- 「**いちばん近い良い場所へ移動**」は、人物を問題のないいちばん近いマスへ移します。
- 「**… マスを道の高さにそろえる**」は、いちばん近い道からその場所までの地面の高さを変えて、パーティーが歩いて行けるようにします。絵は変わらないので、道のように見せたい場合は「**ペイント**」を使ってください。これは普通の未保存のペイントなので、保存すれば残り、「元に戻す」で取り消せます。
- 「**それでもここに追加…**」は、ストーリーのイベントで道が開く場合など、あなたのほうが事情をわかっているとき用です。

「**人物を移動**」で人物をドラッグしたときも、手を離したときに同じ確認が行われます。

### 人物に話させる

人物をクリックします。「**何か話させる…**」を押すか、すでに話す人物なら「**ストーリーの場面用のセリフを追加…**」を押します。

### 中身を変える

一覧の各イベントには、該当する場合に次のボタンがあります:

- 「**言葉を変更**」はライターを開きます。
- 「**条件…**」はイベントがいつ起きるかを決めます: 「**常に**」、ストーリーフラグが立ってから（「**次が立ってから…**」）、または立っていない間だけ（「**次が立っていない間…**」）。フラグは名前で一覧表示されます。「この場所専用のフラグ」は、パーティーがその場所に入るたびにリセットされます。
- 「**削除**」は削除します。

### ライター

普通に入力します。空行で新しい会話ウィンドウが始まり、プレビューにはゲーム内でのウィンドウの見え方が表示されます。「**＋ 主人公の名前**」は、プレイヤーが付けた名前を挿入します。ゲームのフォントには、アクセントのない普通の英字、数字、記号しかありません。カーリークォート、長いダッシュ、「…」は自動で普通の形になり、それ以外のフォントで描けない文字は保存時に拒否されます。

あなたの言葉は新しい行として追加され、ゲーム自身のテキストが上書きされることはありません。同じ行がほかの所でも使われていれば、そちらは元のままです。

### 共有されたシーン

人物やイベントをほかの場所と共有している場所があります。ここでの変更がそちらにも表れる場合、パネルが警告します。

## ドア

「**ドア**」（D）を押します。すべてのドアが行き先とともにマップに表示されます。**青**のセルはドアで、**赤**のセルはどこにもつながっていません。

- **ドアを変更する:** ドアをクリックし、「**行き先を変更…**」を押して場所を選び、その場所のマップでパーティーが到着する位置をクリックします。
- **ドアを作る:** ほかの場所をクリックし、「**ここにドアを作る…**」を押します。ゲーム内のどこにでもつなげられます。
- **ドアを削除する:** ドアをクリックし、「**ドアを削除**」を押します。そのセルは地面に戻ります。
- **ドアをたどる:** ドアをクリックし、「**行き先へ →**」を押します。つながる先の場所が到着地点に印の付いた状態で開き、「**← … に戻る**」でドアに戻れます。

ドアの変更は、その場所のすべてのストーリー段階に反映されます。シーンのスクリプトが開くドアも見つかります: 行き先は変えられますが、スクリプト自体はそのままです。

## 人物を移動

「**人物を移動**」（P）を押します。

1. 「**ストーリーとシーン**」パネルで、シーンと、人物または到着地点の表を選びます。
2. マップ上でドラッグします。手を離すときに ⇧ を押していると、8 ピクセル単位にそろいます。
3. 保存します。

到着地点とは、場所に入ったときにパーティーが現れる地点です。人物にカーソルを合わせると、それが誰で、何を話すかが表示されます。ストーリーで登場するまでマップの外で待っている人物は、たいてい左上の隅にまとまっていて、「×6」のような人数付きで1人だけ描かれます。ドラッグして外に出すと配置できます。

## スタンプ: コピーと貼り付け

「**スタンプ**」（S）を押します。

1. マップ上で長方形をドラッグしてコピーします。
2. クリックして貼り付けます。ここでも、同じブロックセットを使う別の場所でもかまいません。
3. Esc を押すとコピーに戻ります。

- 「**通行設定と高さ**」は、ブロックと一緒にそれらもコピーします。最初からオンになっています。
- 「**オブジェクトのみ**」は、木などのオブジェクトだけを貼り付け、その下の地面は貼り付けません。
- 1回の貼り付けは「元に戻す」1回分で、コピーした内容は場所を切り替えても、再読み込みしても残ります。
- ブロックセットが異なる場所では、すべてのブロックが違う絵になってしまうため、貼り付けは拒否されます。

## 自分の画像を読み込む

「**画像を読み込む…**」はスタンプのパネルにあります。画像をほかの場所と共有していない場所で使えます。ゲームの新しいコピーでは、182 か所のうち 27 か所です。それ以外の場所では、あなたの画像がほかの場所の見た目まで変えてしまうため、エディターは拒否します。

1. 「**オーバーレイ**」（透明な背景で地面の上に描かれます）か「**地面**」を選びます。
2. 「**画像を読み込む…**」を押して、PNG、GIF、BMP のいずれかを選びます。範囲は 16×16 ピクセルのマス 256 個まで、たとえば 256×256 ピクセルですが、細かい画像はそれより早く空きがなくなることがあります。その場合はエディターが知らせます。
3. プレビューを確認します。ゲームが実際に描く色と、残りの空きが表示されます。
4. 「**タイルセットに追加**」を押します。新しいブロックがスタンプのクリップボードに入るので、クリックして配置できます。

画像はこの場所の色に合わせられ、繰り返し出てくる部分は空きを節約するために再利用されます。シートがいっぱいになると、エディターはその場所で使われていないブロックの画像を再利用し、それらのブロックはパレットから消えます。

## ストーリーとシーンの表

「**ストーリーとシーン**」パネルには、このマップを使うシーンと、その裏にある表が、「到着地点: 通常」のようなわかりやすい名前で表示されます。到着地点と人物はマップに表示されます。出口は一覧として編集し、選んだ到着地点が存在するかが確認されます。たいていは、ドア、イベント、人物を移動のツールのほうが簡単です。

## 場所の中のバトル

「**バトル…**」を押すと、いまいる場所のランダムバトルが表示されます。バトルの起きる頻度と、出てくる敵のグループ、それぞれが出る確率です。変更したら「**保存**」を押します。たいていの洞窟やダンジョンでは、どこを歩いてもバトルが起きます。一部の場所では、通行設定で「**エンカウント地面 A**」に塗ったマスの上だけで起きます。ほかの場所とバトルを共有している場所もあり、その場合はダイアログにそう表示されます。変更はそのすべての場所に反映されます。

## つながり

「**つながり**」を押すと、任意の場所が中央に表示され、そこにつながるすべての場所が左に、そこからつながるすべての場所が右に並びます。場所をクリックするとそこへ移動し、「**開く**」を押すとエディターでそのドアに移動します。検索欄で場所を探せます。

## 全体マップ: すべての場所を一度に

「**全体マップ**」を押すと、すべての場所が1枚のキャンバスに並び、ドアや出口でつながる場所どうしが線で結ばれます。Golden Sun の場所は端と端でつながっていないので、全体マップは自分で場所を配置します: 町やダンジョンはそれぞれワールドマップ上の位置の近くに置かれ、その家や部屋が入口から順に横に並びます。

- 背景をドラッグすると見回せ、スクロールでズームできます。「**全体表示**」ですべてが表示されます。
- 場所にカーソルを合わせると、そのドアと、つながる先の場所が強調表示されます。
- 場所をクリックするとエディターで開きます。ドラッグすると移動できます: 全体マップは置いた位置を覚えていて、「**配置を元に戻す**」ですべて元の位置に戻ります。全体マップでの場所の配置はあなた専用で、ゲームは変わりません。
- 実線はドアから出ています。破線は、ストーリーのシーンやスクリプトが使う出口です。

## ワールドマップ

場所の一覧のいちばん上でワールドマップを選びます。戻るには「**← 場所**」を押します。

| ツール | キー | 何をするか |
|---|---|---|
| **表示** | V | カーソルを合わせると、その場所の地域と働きが表示されます。町、ダンジョン、青い踏むと反応する場所をクリックすると、行き先が表示されます。 |
| **地面** | G | 地面のブロックをペイントします。⌥-クリックでブロックを拾え、最近使ったブロックは手元に残ります。 |
| **オーバーレイ** | O | 山、木、海岸線をペイントします。歩けるかどうかは両方のレイヤーのタイルで決まります。 |
| **地域** | R | エンカウント地域をペイントします。地域ごとにランダムバトルがあり、それぞれ中にある町の名前で呼ばれます。「**ここでのバトル**」では、平地と森で、バトルの起きる頻度と、出てくる敵のグループを変えられます。 |
| **町** | T | 町やダンジョンをドラッグして移動します。クリックすると行き先を変えられます。「**新しいアイコンを置く…**」で、ゲームの町が使っている絵を使ってアイコンを追加できます。自分で追加したアイコンは削除できます。 |
| **移動マス** | P | 青いマスは、踏むとどこかへつながります。クリックすると行き先を変えたり削除したりでき、ほかのマスをクリックすると新しく作れます。「**マスを追加…**」で移動マスを広げられます。追加するマスをクリックし、Esc を押します。 |

- 「**通行設定**」「**エンカウント地域**」「**場所**」にチェックを入れると、それらがマップに表示されます。
- 町を移動するとき、「**到着地点（出たときに現れる場所）も一緒に移動する**」を使うと、町を出たときに町のすぐ横に現れるようになります。最初からオンになっています。
- 変更はペイントするたびに保存されます。「**元に戻す**」で最後のひと塗りを取り消し、「**やり直す**」で戻します。
- ポーズ画面のマップは別の画像なので、あなたの変更には追従せず、新しいアイコンの印も表示されません。

## チェック: 問題を見つける

「**チェック**」を押すと、あなたの変更が引き起こす問題がないか、すべてのマップを調べます。問題ごとに直し方と、その場所を開いてマスを数秒間丸で囲む「**表示**」ボタンが付きます。調べる内容は次のとおりです:

- どこにもつながっていないドアや、存在しない到着地点につながっているドア。
- 開けられない宝箱、中身が決まっていない宝箱、中身が復活する宝箱、「開封」フラグを共有している宝箱。
- 1つの場所に 10 個を超える宝箱とストーン。
- その場所にないブロックや高さを使っているマス。
- あなたが書いた行のうち、ゲームのフォントで描けないもの。
- ファイルが壊れている場所。
- ゲームのソースが更新されて、合わなくなった編集。

元のゲームにもそれ自体のクセがあり、それらは「**元のゲーム自体のクセも表示する**」にチェックを入れない限り隠されます。編集した場所では、元のゲームにもともとあったクセが、あなたのものとして表示されることがあります。場所のページでは、プレイ、書き出し、「**ビルド**」の前に自動でチェックが実行され、問題があれば続けるか確認されます。ワールドマップのページでは、プレイとビルドはチェックを実行しないので、場所のページからチェックを押してください。チェックが完了できなかった場合は、そう伝えて、続けるか確認します。

## ゲームをプレイする

「**▶ プレイ**」を押します。保存、チェック、ビルドを行い、編集している場所からゲームを mGBA で開きます。ワールドマップのページからは、チェックをせずにビルドし、ワールドマップから始まります。

- プレイは毎回**新しいゲーム**です: Isaac が1人だけで、ストーリーも進んでいないため、場所が序盤の姿で表示されることがあります。
- 現れるのは、見ている位置ではなく、その場所の到着地点のうち、ゲームの歩行ルールでパーティーが歩いて出られる最初の地点です。ストーリーのシーンは考慮しないので、いくつかの場所ではシーンの中から始まることがあります。そうなったら、▶ プレイの隣の「**開始地点**」で別の到着地点を選び、もう一度プレイを押してください。
- マップを変更した後のビルドには約 20 秒かかります。
- 開始地点は使い捨てのゲームのコピーにしか存在しないので、書き出した MOD は普通にタイトル画面から起動します。

## MOD を共有する

「**MOD を書き出し…**」を押します。

1. 「**名前**」を入力し、必要ならあなたの名前と変更内容も書きます。
2. 「**書き出し**」を押します。

`~/Documents/GSMapEditor/Exports/` に、小さな `.bps` パッチとプレイヤー向けの説明書ができます。「**Finder で表示**」を押すと確認できます。同じ名前でもう一度書き出すと、前のパッチを置き換えるか、残して新しいほうに番号を付けるかをエディターが尋ねます。書き出しは先にチェックを実行し、各パッチを1回テストして、あなたのビルドを正確に再現できることを確かめます。

プレイヤーが古いパッチャーを使う場合は、「**古いパッチャー用に .ips も保存する**」にチェックを入れます。IPS は移動したデータを記録できないため、ずっと大きくなります。

**共有するのはパッチだけにして、ビルドしたゲームは絶対に共有しないでください。** プレイヤーは自分のコピーにパッチを当てるので、ゲームそのものを配ることはありません。`.bps` パッチは、このエディターのほか、Rom Patcher JS や Floating IPS などの一般的なパッチャーでも使えます。

## ほかの人の MOD を遊ぶ

「**パッチャー…**」を押します。

1. 「**パッチを選択…**」を押して、`.bps`、`.ips`、`.ups` のいずれかのファイルを選びます。
2. パッチを当てるゲームを選びます: 「**この Mac でソースからビルドした改造前のゲーム**」（ROM 不要）か、「**自分の ROM ファイル**」です。
3. 「**パッチ**」を押します。

パッチを当てたゲームは `~/Documents/GSMapEditor/Patched/` に保存され、「**mGBA でプレイ**」や「**Finder で表示**」を押せます。BPS と UPS のパッチは、違うゲームには当たりません。IPS のパッチは確認ができず、パッチャーがそのことを伝えます。

## 作業データの保存場所

| 何 | どこ |
|---|---|
| あなたの MOD | ゲームのソースフォルダーの中。既定では `~/Documents/GSMapEditor/alchemy/` |
| 書き出したパッチ | `~/Documents/GSMapEditor/Exports/` |
| パッチを当てたゲーム | `~/Documents/GSMapEditor/Patched/` |
| エディターの設定と「元に戻す」の履歴 | `~/Library/Application Support/GS Map Editor/` |
| 一時的なビルド（削除しても安全） | `~/Library/Caches/GSMapEditor/` |

Windows と Linux では、最初の3つは Linux のホームフォルダーの `~/GSMapEditor/` に、設定は `~/.config/gs-map-editor/` に、一時的なビルドは `~/.cache/gs-map-editor/` にあります。

MOD をバックアップするには、ゲームのソースフォルダーを安全な場所にコピーします。あなたの変更は、そのフォルダーの中の普通のファイルです。

## まだできないこと

- **The Lost Age**、および英語版以外の版。
- パッケージ化されたアプリとしての **Windows や Linux** 版。
- **まったく新しい場所:** 場所を追加するボタンはありません。
- **バトルとゲームデータ:** モンスター、アイテム、ショップ、音楽は編集できません。ゲームにある敵のグループのうちどれをどこに出すかと、その頻度は選べますが、新しいグループは作れません。
- **ストーリーのスクリプト:** 人物が何をいつ話すかを変えたり、簡単なイベントを追加したりはできますが、カットシーンは書けません。
- **ポーズ画面のマップ。**

| 「プレイには mGBA が必要です」 | [mgba.io](https://mgba.io) からインストールし、もう一度プレイを押してください。 |
| ゲームのソースが読めないバージョンだと表示される | ソースが、このエディターがまだ理解できない形に変わっています。そのフォルダーを別の場所に移してから、セットアップ画面の「**ダウンロード**」を使ってください。MOD は移したフォルダーの中に残っています。 |
| 「変更をゲームにできませんでした」 | ファイルは無事です。あなたが書いた行が示されていれば、その言葉を変えてください。そうでなければ、ビルドできるまで「**元に戻す**」を使い、「**詳細を表示**」を押してビルド自体のメッセージを確認してください。 |
| 「この場所のファイルが読み込めません」 | ファイルのどれかが壊れています。「**場所をリセット…**」を使うか、最近の保存が原因なら「**元に戻す**」を使ってください。 |
| 「人物・ドア・イベントの編集を保存したファイルが読み込めません」 | 「**元に戻す**」を使ってください。それでも直らなければ、そのファイルをバックアップから復元してください。 |
| 「この場所にはこれ以上置く空きがありません」 | 看板と足元メッセージ用のコードが、この場所では尽きています。追加したものを1つ削除してください。 |
| 「ゲームのフォントに…がない」 | その文字を、普通の英字と記号に置き換えてください。 |
| セットアップ画面に、フォルダーのパスに空白が含まれていると表示される | ビルドは空白を含むパスを扱えません。パスに空白のないフォルダーにあるゲームソースのコピーを選んでください。 |
| アプリがエラー付きのセットアップ画面で開く | メッセージに、何が読めなかったかが書かれています。直したら「**もう一度チェック**」を押してください。 |
| 「問題が発生しました」 | その操作は完了しませんでした。もう一度試し、何度も起きる場合はアプリを再起動してください。 |
| 「このマップは別のブロックセットを使っています」 | スタンプは、同じブロックセットを共有する場所の間でしか貼り付けられません。 |
| 「この場所は画像をほかの場所と共有しています」 | 画像の読み込みは、自分の画像を持つ場所でしか使えません。メッセージに、使える場所がいくつか示されます。 |
| 「そのブロックは…使用停止になりました」 | その画像は、読み込んだ画像のために再利用されました。別のブロックを選んでください。 |
| 「ゲームにはこれ以上宝箱を置く空きがありません」 | ゲームの空いている「開封」フラグが尽きています。追加した宝箱を1つ削除してください。 |
| ゲーム内で宝箱がない | 1つの場所に表示されるのは、最初の 10 個の宝箱とストーンだけです。「**チェック**」を実行してください。 |
| チェックで編集が「今は合わない」と表示される | その編集の下でゲームのソースが変わりました。編集は残っていますが、ゲームからは外されています。 |
| 場所が編集した内容と違って見える | 別の「**ストーリー段階**」を見ているのかもしれません。また、プレイは新しいゲームから始まるので、序盤の姿が表示されます。 |
| セットアップが途中で失敗した | 「**もう一度チェック**」を押してから、その手順のボタンを押してください。チェックリストの下のログに、何が起きたかが表示されます。 |
| Windows: エディターがブラウザーで開かなかった | 小さな GS Map Editor のウィンドウにアドレスが表示されているので、ブラウザーにコピーしてください。 |
| Windows: インストーラーが Ubuntu の準備ができていないと言う | 求められていれば Windows を再起動し、スタートメニューから **Ubuntu** を一度開いてユーザー名とパスワードを決めてから、もう一度インストーラーを実行してください。 |

## 問題を報告する

何をしていたか、何が起きたか、そして Mac のチップと macOS のバージョンを添えて、[issue を開いてください](https://github.com/TRosenvall/GS-Map-Editor/issues/new?template=bug_report.md)。エディターが「**詳細を表示**」やセットアップのログを表示しているときは、「**バグ報告用に詳細をコピー**」を押して貼り付けてください。ROM やゲームのファイルは添付しないでください。

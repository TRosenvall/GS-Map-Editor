GS Map Editor makes your own version of Golden Sun: The Broken Seal without writing code. Repaint towns, hide chests, write new dialogue, add people and doors, reshape the world map, then press **▶ Play** and walk around in your change.

**New in 0.2.0: a first Windows version, and I need Windows testers.** It has been tested on Linux, which is what it runs inside, but never on a real Windows PC. If you try it, please [report how it went](https://github.com/TRosenvall/GS-Map-Editor/issues/new?template=bug_report.md), whether it worked or not. The Mac version is unchanged apart from the Intel download's name, so Mac users on 0.1.0 needn't update.

## Which download?

- **Windows 10 or 11:** `Install-GS-Map-Editor.cmd`
- **Mac with Apple Silicon** (M1, M2, M3, M4 and later): `GS-Map-Editor-0.2.0-AppleSilicon.dmg`
- **Mac with Intel:** `GS-Map-Editor-0.2.0-Mac-Intel.dmg`

Not sure which Mac? Apple menu → **About This Mac**. "Chip: Apple M…" means Apple Silicon, "Processor: … Intel …" means Intel.

Everyone needs about 3 GB of free space, an internet connection for the first setup, and [mGBA](https://mgba.io/downloads.html), a free emulator, to play. On Windows, use mGBA's Windows installer.

## Windows (early test)

The editor runs inside WSL, the Linux that's built into Windows, because that's the only way the game's source builds on Windows. It opens in your web browser.

1. Download `Install-GS-Map-Editor.cmd`. If your browser says it isn't commonly downloaded, choose **Keep**.
2. Double-click it. Windows says it protected your PC because the installer isn't signed yet: press **More info**, then **Run anyway**.
3. The first time, it turns on WSL and installs Ubuntu. Windows asks for administrator permission, and may ask you to restart. If it does, restart and double-click the installer again.
4. When Ubuntu asks, choose a username and a password. Typing the password shows nothing; that's normal. Remember it: the next step asks for it.
5. The installer then sets up the editor inside Ubuntu and adds **GS Map Editor** to your Start menu and desktop.

Open **GS Map Editor**. A small window appears (keep it open while you use the editor; closing it stops the editor) and the editor opens in your browser. The first time, it walks you through downloading and building the game, in about 15 minutes. Keyboard shortcuts use Ctrl where the README says ⌘, and Alt where it says ⌥.

## Mac: opening it the first time

The app isn't signed with an Apple developer certificate yet, so macOS warns about it:

1. Open the `.dmg` and drag **GS Map Editor** into **Applications**.
2. Open it from Applications. macOS says it can't check the app: press **Done** (or **Cancel**).
3. Open **System Settings → Privacy & Security**, scroll down, and press **Open Anyway** next to GS Map Editor. Confirm with your password.

On macOS 14 and earlier you can instead right-click the app, choose **Open**, then **Open** again. You only do this once.

The first run sets everything up for you in about 15 minutes, mostly waiting. It downloads the game's source from [alchemy](https://github.com/PascalPixel/alchemy) and builds the game on your computer. No ROM is needed, and none is included.

## Known issues

- You can't remove a person you've added yet (Undo last save takes it back).
- ▶ Play sometimes starts you somewhere you can't walk from (about 4 places in 200). Pick another point under **Start at**.
- Exporting twice with the same name replaces the earlier patch.
- On Windows, "I already have a copy" asks you to type the folder's path, and Export and the Patcher save inside Ubuntu, under `GSMapEditor` in your Ubuntu home folder.
- English edition of The Broken Seal only.
